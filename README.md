# ComicCraft - AI Comic Generator

An AI-powered comic strip generator built with Flask and Google Gemini AI. Turns your story ideas into visual comics instantly.

## 🚀 Features
- AI Story Generation using Gemini Pro
- Auto Image Generation for comic panels
- Multiple Art Styles (Manga, Superhero, Cartoon)
- Download comic as PDF/Image
- User-friendly Flask Web Interface

## 🛠️ Tech Stack
- Backend: Python, Flask, routes.py
- AI: Google Generative AI (Gemini)
- Frontend: HTML, CSS, JavaScript
- Deployment: Google Cloud Run

## ⚙️ How to Run
1. Clone the repo
   `git clone https://github.com/sathya dk/ComicCraft.git`
2. Install dependencies
   `pip install -r requirements.txt`
3. Add your Gemini API Key in `.env` file
   `GOOGLE_API_KEY=your_key_here`
4. Run the app
   `python app.py`
5. Open `http://localhost:5000`

## 📂 Project Structure
- `app.py` - Main entry point
- `routes.py` - Main application logic (Story -> Comic generation)
- `templates/` - HTML pages
- `static/` - CSS and JS
